Pivot Table Widget (PPT) for Grist
=======================================

This widget allows you to create a pivot table from Grist source data, based on [pivottable.js](https://pivottable.js.org/examples/) .

This is a redesign of the Widget now integrated into GristLabs, the original author of which is [jperon](https://github.com/jperon)

This version of the widget is developed by [Arthur Panckoucke](https://github.com/Arthurpanck)

### ✅ Improvements to the Original Pivot Table:

-   Complete translation of the interface into French
-   Setting up two view modes :
    -   Creation Mode (editing the TCD)
    -   Full screen mode (readable viewing)
-   Improved readability: larger fonts, better colors
-   Removing unnecessary options to focus on simple and efficient use
-   Excel-inspired labels: Rows, Columns, Σ Value

### 🔧 Classis Informations

This widget builds a [pivot table](https://pivottable.js.org/examples/) from the source data.

Just setting its url gives a pivot table without any row / column definition.
