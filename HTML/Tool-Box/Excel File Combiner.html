Excel File Combiner

Instructions:

  1. Enter a Tenant Name (optional)
  2. Select multiple Excel files (XLSX, XLS, CSV) with the same header row
  3. Click "Combine Files" to merge them into a single table
  4. Use "Copy to Clipboard" to copy the combined data

Note: The app will automatically process "Zip" columns by removing anything after a dash (e.g., "84041-1636" becomes "84041").
