CoStar Tenant Excel Combiner

Instructions:

  1. In CoStar, filter your export by tenant name, then export the Excel file (should include: Property ID, Address, City, State, Zip, Longitude, Latitude).
  2. Drag & drop the exported Excel file below, then enter the Tenant Name used for the export.
  3. Click "Add Tenant Sheet". Repeat for each tenant: export, drag, enter name, and add.
  4. Once all tenants are added, click "Combine All Tenants" to produce a master table.
  5. Export as TSV or copy to clipboard for easy import into your system.

Note: A "Tenant" column will be created/updated for each row. Zip codes will be cleaned to remove anything after a dash (e.g., "84041-1636" → "84041").
